How this works

Right-click an element → Comment on this. Comments save into the source file as hidden <!-- MDV-COMMENT … --> blocks immediately after the element.

Click Save to write back to disk. The AI can then read your comments by opening the file. To add an AI reply, paste the AI's response into the reply form and pick the ai identity. Or have the AI append MDV-COMMENT blocks directly to the file and re-open here.

Identity is local-only — change Author in the composer to attribute. There's no auth here; this is a local iteration tool.
